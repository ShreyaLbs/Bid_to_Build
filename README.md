# Aurora Fest '26: Campus Event Hub

A responsive, frontend-only website where students browse, search and register for fest events.
Built for **BID TO BUILD** at **Yagna Dhuruva '26** (LBSITW, 10 October 2026).

- **Live site:** <paste live link>
- **Repository:** https://github.com/ShreyaLbs/Bid_to_Build

## The problem

A college fest has many events, and students find it hard to see what is on and sign up for the ones they like.

## Our solution

Campus Event Hub puts every event in one place. Students can filter by category, search by name, check how many seats are left and register in under a minute, with clear validation and an instant confirmation.

The design is a festival poster and ticket look: paper background, thick ink borders, hard offset shadows, heavy type, and event cards styled as tickets.

## Features

### Core
- 8+ event cards from dummy data, each with name, category, date, time, venue and short description
- Category filter with an "All" option
- Live search by event name, combined with the category filter
- Registration form with validation for name, email and phone, with clear error messages under each field
- Success pop-up showing the student's name and the event name
- Seats left on every card, with a "Full" state that blocks registration when seats run out
- Header with fest name and logo, footer with contact details
- Hover effects and animations on cards and buttons
- Responsive on mobile, tablet and desktop, with no sideways scrolling

### Bonus
- Registrations and seat counts saved in `localStorage`, so they stay after a refresh
- "My events" list with a cancel option
- Dark mode toggle
- Live countdown to the first event
- Sort options, result count and "Add to calendar" links

## Validation rules

| Field | Rule |
|---|---|
| Name | Required, at least 3 letters, letters and spaces only |
| Email | Required, valid email format |
| Phone | Required, exactly 10 digits, starting with 6, 7, 8 or 9 |
| Duplicate | The same email cannot register twice for the same event |

## Auction tools used

### Bootstrap 5
| Component | Where it is used |
|---|---|
| Grid system and utilities | Page layout, event card grid, spacing and responsive behaviour |
| Navbar and collapse | Header navigation and mobile menu |
| Cards | Event cards |
| Badges | Category labels, seats left, "Full" status |
| Button group | Category filter |
| Input group | Search box |
| Form controls and validation classes | Registration form (`is-valid`, `is-invalid`, feedback messages) |
| Modal | Registration form and success pop-up |
| Offcanvas | "My events" panel |
| Toast | Cancellation and action confirmations |
| Tooltip | Icon-only buttons |
| Progress bar | Seats taken |
| `data-bs-theme` | Light and dark theme switching |

### Font Awesome
Icons for the logo, event categories, date, time and venue details, seat status, buttons, the theme toggle, the success check mark and social links in the footer.

## Tech stack

HTML, CSS and JavaScript only. Bootstrap 5 and Font Awesome are loaded from a CDN. No backend, no other libraries or frameworks.

## Project structure

```
index.html   Page structure and Bootstrap components
style.css    Theme variables (:root), poster styling, responsive rules, animations
script.js    Event data, card rendering, filter and search, validation, registration, storage
README.md    Project documentation
```

## Code quality

- HTML, CSS and JavaScript are in separate files
- All colours, fonts and radii are defined once in `:root` variables
- Event cards are generated by a single reusable render function
- Validation rules live in one reusable place
- Clear names and section comments throughout

## How to run

1. Download or clone the repository
2. Open `index.html` in any modern browser

No installation or build step is needed.
